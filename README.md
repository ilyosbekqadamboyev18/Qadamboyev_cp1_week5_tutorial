# 🎯 Python Tactical Shooter (CS:GO Style Demo)

A lightweight 2D top-down tactical shooter built using **Python** and **Pygame-CE**. This project is designed to demonstrate core game development concepts like game loops, vector math for aiming, collision detection, and enemy AI.

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)
![Pygame-CE](https://img.shields.io/badge/pygame--ce-latest-green.svg)

---

## ✨ Features

* **Tactical Movement:** Smooth player movement with collision detection against map obstacles (walls).
* **Mouse-Based Aiming:** The player's weapon dynamically rotates and points toward the mouse cursor.
* **Shooting & Combat:** Shoot bullets that interact with map barriers and eliminate enemies.
* **Enemy AI:** Enemies spawn continuously and track the player's position.
* **HUD Overlay:** Real-time health tracking and score counter.

---

## 🎮 Controls

| Action | Control |
| :--- | :--- |
| **Move Up / Down** | `W` / `S` or `Up / Down Arrow Keys` |
| **Move Left / Right** | `A` / `D` or `Left / Right Arrow Keys` |
| **Aim** | `Mouse Cursor` |
| **Shoot** | `Left-Click` |
